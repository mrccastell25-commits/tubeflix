Como funciona a extração?
• Sem API Key: tenta carregar a playlist pública "raspando" a página do YouTube via proxies de terceiros. É um método sujeito a falhas (o YouTube pode bloquear, exibir aviso de cookies, ou os proxies podem estar fora do ar) — se der erro, tente novamente em instantes ou use a API Key abaixo.
• Com API Key (recomendado): usa a API oficial do YouTube v3, muito mais confiável e sem depender de proxies externos. Crie sua chave de graça no Google Cloud Console (leva menos de 2 minutos).
